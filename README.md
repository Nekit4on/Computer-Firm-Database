## 📌 О проекте

**Курсовой проект по дисциплине «Базы данных»**  
**Тема:** Проектирование базы данных для компьютерной фирмы  
**Студент:** Черных Никита Максимович, группа бОИС-241  
**ВУЗ:** Воронежский государственный технический университет (ВГТУ)

Информационная система предназначена для автоматизации деятельности компьютерной фирмы, осуществляющей продажу компьютерной техники, комплектующих и сборку готовых конфигураций ПК.

---

## 🎯 Цель проекта

Разработать полноценную клиент-серверную информационную систему, которая позволяет:
- вести учёт клиентов, сотрудников и поставщиков;
- управлять складскими остатками комплектующих;
- формировать готовые конфигурации ПК;
- оформлять и отслеживать заказы;
- вести историю изменений цен и статусов заказов;
- формировать аналитические отчёты;
- разграничивать права доступа пользователей.

## 📂 Структура базы данных

База данных содержит следующие основные таблицы:

| Таблица | Назначение |
|---------|------------|
| `clients` | Информация о клиентах |
| `employees` | Данные о сотрудниках |
| `users` | Учётные записи и роли пользователей |
| `suppliers` | Поставщики комплектующих |
| `component_types` | Типы комплектующих |
| `components` | Складской учёт комплектующих |
| `configurations` | Готовые сборки ПК |
| `configuration_components` | Состав конфигураций |
| `orders` | Заказы клиентов |
| `order_items` | Позиции заказов |
| `order_status_log` | История изменения статусов заказов |
| `component_price_history` | История изменения цен |
| `sales_statistics` | Агрегированная статистика продаж |
| `inventory_movements` | Движение комплектующих на складе |

> Модель данных приведена к **третьей нормальной форме (3НФ)**.

## 🖥️ Функциональные возможности

### 🔐 Авторизация и разграничение прав

В системе реализованы три роли пользователей:

| Роль | Доступные функции |
|------|-------------------|
| **Admin** | Полный доступ ко всем модулям системы |
| **Manager** | Работа с клиентами, заказами, конфигурациями, отчётами (без изменения цен и удаления) |
| **Stockman** | Только управление комплектующими и складскими движениями |

### 📋 Основные модули

1. **Управление клиентами** — добавление, редактирование, удаление, поиск, экспорт в Excel/Word
2. **Управление комплектующими** — учёт остатков, цен, привязка к поставщикам и типам
3. **Управление заказами** — создание, редактирование, изменение статусов, автоматический расчёт суммы
4. **Управление поставщиками** — хранение контактной информации
5. **Аналитическая отчётность** — 7 видов отчётов:
   - Продажи по периодам
   - Топ клиентов
   - Популярные сборки
   - Склад
   - Эффективность менеджеров
   - Движение по складу
   - История изменения цен
